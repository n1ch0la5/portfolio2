# Design identity

One adjective: **workshop**. This is a builder's portfolio — it should feel like
an engineer's bench, not a startup landing page. Any future change (human or AI)
inherits these commitments; do not regress to defaults.

## The five commitments

1. **Neutral scale**: near-black ground `#0b0c0f` (overrides `gray-950` in
   `globals.css`), gray-400 body text, white/5 + white/10 surfaces. No slate,
   no zinc.
2. **Radius stance**: sharp. Zero border radius on cards, buttons, chips, and
   badges. Round is reserved for things that are literally dots (timeline
   markers, the chat icon disc).
3. **Type pairing**: Bricolage Grotesque for display (h1–h3), IBM Plex Sans for
   body. Never Inter.
4. **One accent**: blue (`blue-600` fills, `blue-400` text). Used sparingly and
   flat — no gradient washes, no glow blobs, no second accent. Emerald appears
   only as a status badge color.
5. **Signature token**: IBM Plex Mono for all "data" text — the NJ logotype,
   location line, dates and period tags, stat-tile labels, tech chips, contact
   details, footer. Prose is sans; facts are mono.

## Voice

Plain sentences, concrete nouns, first person. Say what was built and for whom.
No "elevate/seamless/passionate", no em dashes in outward copy, no exclamation
marks doing the enthusiasm's job. CTA labels are verbs a person would say:
"See the work", "Email me".
